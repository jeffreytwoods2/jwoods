# jwoods.dev

A personal homepage to show off the things I build

<br />

## Overview

I aim for this project to be

1. dead simple,
2. performant,
3. and dependency-free,

in that order.


#### Dead Simple

I can't fathom why this project would require anything other than HTML, CSS, and nginx. You do not need Vite to tree-shake a Renuxtified SPA to send a static page to the client.

#### Performant

I want every page to render smoulderingly fast on the worst device you own. Optimizing a website this simple is actually pretty fun, probably because there's so little to do.

#### Dependency-Free

My jaw drops every time I initialize a Next.js project and npm pulls in 75 packages ("16 vulnerabilities, 1 critical"). What on God's green earth is going on in the JavaScript community?

## Tech Stack

* Ubuntu Server
* HTML5
* CSS3
* Nginx
